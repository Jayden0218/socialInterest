# Approval records

The project owner's explicit permission to incur cost. Per the constitution's Cost and
Environment Constraints, **approval for one piece of work is not approval for the next**.

No approval has been granted. Every ⛔ GATED task in
`specs/002-production-readiness/tasks.md` is therefore unstarted, and the register below
records `unverified` for every entry that needs one.

| id | scope | ceiling | granted_at | granted_by |
|---|---|---|---|---|
| _(none)_ | | | | |

## Format

| Field | Meaning |
|---|---|
| `id` | `A-n` |
| `scope` | Exactly what was approved. One verification, or one named measurement window |
| `ceiling` | Maximum authorised spend |
| `granted_at` | Date |
| `granted_by` | The project owner |

An approval covers **one scope**. Reusing it for a different purpose is a
violation, not a shortcut.
