## T217 — the matrix, and a miscount in the task itself

```
001/SC-009 + 004/SC-005: 1470/1470 post assertions run (15/15 post surfaces built).
005/SC-005: 18/18 review assertions run (place reviews built).
surfaces without a routing probe yet: none
```

**1,390 → 1,488.** A collection's posts are the fifteenth POST surface: 15 × 7 states × 7
viewers × 2 privacy settings = 1,470, plus 18 review assertions.

**T217 said "all 17 surfaces" and there are 16.** The delta contract numbers the saved list
as surface 17 while re-asserting it under the new privacy axis — it was already surface 9, so
it is one surface counted twice, not a seventeenth. 12 surfaces before 008, plus the Following
feed, post search, comment replies and collection posts, is 16. The number in the task was
wrong and this is the correction rather than a quiet re-tally.

A bigger green number is not the goal. 004 recorded that 462 assertions all running the same
`decide()` would mean one function tested 66 times, which is why **T218** matters more than
T217: `surface-routing.spec.ts` reports no surface without a probe, and the collection probe
stubs the repository so it fails if the read path ever returns membership rows directly — the
defect this codebase has shipped seven times.

## T219 — SC-017, and the half that stays open

`safety-fit.spec.ts` now measures every control this feature added, at 130% text on a 640pt
viewport. Phase D's two cases were verified RED by taking `scroll` off Edit profile.

**The font half is NOT closed and must not be reported as if it were.** react-native-web
ignores the platform font setting entirely — which is why 006's `Avatar` overflow was
invisible there — so a browser result closes the SCREEN-SIZE half only. That has been the
position since 006 and 008 does not change it.

`browser/compose-fit.spec.ts` is new and is a screen-size measurement of a different kind: it
asserts the media strip stays ONE ROW whatever the media count, with the fold as the
consequence. A guard asserting only the number passes again the moment a tile shrinks.

## T224 — grep the COPY, and it found two things

007 shipped a follow hint describing a withdrawn requirement because only the code was
updated. Doing the grep this time found two pieces of copy that US13 and US15 made untrue:

- **The share sheet said nothing for a public post** — which reads as "anyone can open
  this" — and a public post by a PRIVATE account is evaluated by the `followers` rule. The
  post's visibility really is `public` and the switch really was exhaustive, so nothing in
  the code would have shown it. `share-warning.test.ts` pins the corrected copy.
- **The saved list's empty state told somebody to save a post they had already saved.**
  "Nothing saved yet. Tap the star." is true of the whole list and wrong of an empty shelf —
  those posts are saved, they are just not filed there. Copy that describes a product where a
  collection is a box, on a screen whose whole point is that it is a shelf.

## T210 — a task that turned out to be a "no"

Recorded here because a "no change needed" that is not written down reads later as an
omission. Collection names are **not** reportable: a collection is readable only by its owner
(FR-050), so its name has an audience of one, there is no reporter, and a subject nobody else
can see would be an undecidable item in the moderation queue. `CollectionRepository` has no
`removeName` for the same reason — a remover nothing can call would be the sixth
declared-half-with-no-other-half this feature exists to end.

`collections-are-not-reportable.spec.ts` pins the reasoning AND **the condition that overturns
it**: it fails the moment any collection route stops being on `/me`.
