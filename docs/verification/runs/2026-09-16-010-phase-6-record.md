## What Phase 6 actually found

Five tasks were done and unticked; the rest of the work was finding things the engine swap
had left pointing at the old one. **None was found by a test failing.**

| Stale reader | What it would have done |
|---|---|
| `durability.spec.ts` | Queried a table nothing had written to since the swap. Failed loudly — the only one that did. |
| `backfill-conversation-state.ts` | Thrown on `repo.doc.send`. **Typechecked clean**, because it reached through an `as unknown as` cast. |
| `bench:ceiling`, `bench:feed-load` | Timed DynamoDB Local and printed the figure **labelled as the datastore**, in the two files whose subject is what a number is a number about. |
| `verify:local` | **PASSED** by exercising a container the product never talks to — from the script whose whole job is to say the local profile works. |
| `seed:load` | Stale in two directions: DynamoDB `BatchWrite`, and a hierarchy 013 deleted. |
| Four ffmpeg fixtures | Required a container runtime on a machine with a native ffmpeg, and made T028 unrunnable. |
| `.env.example` | Handed you `LOCAL_JWT_SECRET=dev-only-not-a-real-secret` — the value the service refuses BY NAME — and no `DATABASE_URL` at all. The README's second line is `cp .env.example .env.local`. |
| `db:create-local` | Named in **eight** instructional documents after the script it ran was gone. |

**The ceiling re-measured, and the order of magnitude is gone.** Postgres: generator 366,725,
datastore **4,205**, application 4,342 req/s. The emulator was 827, then 882 on the durable
stack. So the datastore is ~4.8× faster and now within 3% of the application — "the datastore
is the constraint" is no longer a safe reading. **It still says nothing about D1**: a
container on this machine is a stand-in, which is why `harness.ts`'s `STAND_INS` had to gain
`postgres-local`, `localhost` and `127.0.0.1`. Without that it would have classified a laptop
figure as a production datastore, silently, in the direction that flatters the number.

**A false regression caused on purpose.** 200 seeded posts turned `008/US13 FR-043` red in the
full API suite while it passed alone — the grown-table shape for the fifth time here.
`db:create-local-pg --recreate`, then 2,165/2,165 again. `seed:load` says so in place now.
