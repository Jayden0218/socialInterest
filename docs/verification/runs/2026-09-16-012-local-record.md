## T001 is blocked by the environment, and two real defects were found getting there

`capture-screens.ts` could not run. Two harness defects, both fixed:

1. `resetStore()` threw on `s3:create-local` before a single screenshot — MinIO
   publishes to quay.io, which this environment's egress blocks. Now tolerated
   for a **refused connection only**, and loudly. Any other failure still
   throws, and CI runs MinIO so the branch cannot hide a break there.
2. The API it spawns died on `DATABASE_URL is not set`, while `resetStore` had
   just recreated that same database — every other part of the harness reads
   `e2eEnv.postgresUrl`. The harness is a caller, and a caller is where a local
   default belongs; the API's own no-default rule (003/FR-007) is untouched.

It now reaches the media-publish step and fails there. That is the object store
again and **cannot be fixed from inside this sandbox.** So T015, T025 and T031
are blocked with it, and the browser spec written for T014
(`card-is-image-dominant.spec.ts`) is **written and not run**.

## Device verification: NOT RUN

No emulator in this sandbox. Nothing in 011 had run on a device either, and
nothing in 012 has. `react-native-svg` resolves and the web bundle builds, which
says the icons compile and render under react-native-web — **it says nothing
about a device**, where the SVG library is a native module. Principle V.

## Guards, and what each of them caught

Every guard here was watched RED against the real product first.

- **`every-action-has-an-icon`** — 13 offenders across 7 files, where the task
  predicted 2.
- **`four-states`** — named exactly the two surfaces not yet converted.
- **`every-route-is-reachable`** — named `people-search` on both halves.

**Three defects in my own guards, found before they were trusted:**

1. The icon guard accused `é` inside the word "café" — a hand-written notion of
   "not ASCII" where the question is whether Unicode calls it a letter. A guard
   that accuses correct code gets switched off.
2. Worse: its JSX branch refused to match any text containing `{`, so
   `<Text>💬 {commentCount}</Text>` was invisible — **the exact `glyph {count}`
   shape the spec names as the defect.** It returned eleven offenders and looked
   authoritative while missing one in a file it had already flagged twice.
3. T012 was nearly signed off on a break that never happened: the
   deliberate-break edit was a silent no-op and the suite stayed green, which
   reads identically to a guard passing. The replacement asserts the file
   changed before believing the result.

## Three things I built wrong and the tests caught

1. **The states first WRAPPED each screen**, replacing the chrome along with the
   content: the inbox lost its new-group control and the feed lost its
   For You / Following switcher — so an empty feed offered no way to stop being
   empty. FR-007 failing in the act of implementing FR-002.
2. **The state testIDs were composed** as `${testID}-empty`, invisible to every
   source-scanning guard. Made literal — and that is still only a **partial**
   fix, because the snapshot scans `testID=` and `testID:` positions and these
   are in neither.
3. **Two screens decided "empty" from `items.length === 0`**, which cannot tell
   empty from failed from still-loading and said "No messages yet" for a dropped
   connection.

## Deliberate design changes, recorded rather than absorbed

- **Three icons beyond the artboards** — `play`, `send`, `star`. The 16 cover
  the screens the canvas draws; a video badge, a message composer and a place
  rating live on screens it does not. Leaving them as characters would have made
  the set "consistent" by excluding the places it failed to cover.
- **A fourth icon size**, `state: 40`, because `States.dc.html` needs one. Not
  because a screen wanted "a bit bigger", which is what the closed union refuses.
- **The card's byline is gone.** The largest cut taking the photograph from 47%
  to the artboard's 78%. `post-card.test.tsx`'s assertion was **inverted rather
  than deleted** — "we meant to remove it" and "it fell off" look identical in a
  test that simply stops mentioning something.
- **`people-search` was removed, not built.** FR-016 was already satisfied:
  Explore searches people and pushes `{ name: 'person' }`. A second surface for
  one need is how this product got two feed responders.
